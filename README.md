# ministyle-kids

مشروع موقع متجر إلكتروني لبيع الملابس. تم تصميمه عشان يكون سهل الاستخدام ويعرض المنتجات بشكل جذاب.

### المميزات الرئيسية
- `الصفحة الرئيسية`: سلايدر للعروض وأقسام جديدة
- `صفحة المنتجات`: فلترة حسب النوع، السعر، اللون، المقاس
- `تفاصيل المنتج`: معرض صور + اختيار المقاس واللون + اضافة للسلة
- `سلة التسوق`: حساب السعر الاجمالي وحذف المنتجات

### التقنيات المستخدمة
- **Frontend**: HTML5, CSS3, JavaScript ES6
- **الأدوات**: Git, GitHub, VS Code

### ما تعلمته من المشروع
اتعلمت ازاي اعمل فلترة للمنتجات بالـ JS، وادارة سلة المشتريات، وتصميم موقع تجارة الكترونية متكامل.
